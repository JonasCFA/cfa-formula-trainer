# CFA Level I Formula Trainer

An independent, English-language study companion with formula flashcards, numerical examples, related formulas and chapter progress across eight topics.

Open `index.html` in a browser to study locally; no installation or internet connection is needed. Progress is stored in the browser's local storage and is specific to the browser and page origin. Moving between a local file and a hosted page may result in separate progress.

This is a selected formula collection, not a complete CFA curriculum or a reproduction of the linked cheat sheets. Check formula conventions against your curriculum.
